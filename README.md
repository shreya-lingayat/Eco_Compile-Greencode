# 🌱 GreenCode — AST-Powered Sustainable Static Analyzer

GreenCode is a full-stack static code analysis tool designed to help developers write cleaner, more efficient, and more sustainable software. By analyzing source code using Abstract Syntax Trees (ASTs), it aims to identify potential code quality issues and opportunities for optimization.

## 🚀 Features

- **AST-Based Analysis:** Analyze source code structurally rather than relying only on text-based pattern matching.
- **Static Code Analysis:** Identify potential issues in source code without executing the program.
- **Sustainable Coding:** Highlight code patterns that may offer opportunities to improve efficiency and reduce unnecessary computation.
- **Full-Stack Architecture:** Separate frontend and backend components for a modular application structure.
- **Developer-Friendly Insights:** Help developers understand areas of code that may benefit from optimization.

## 💡 How It Works

1. **Source Code Input:** The developer provides source code for analysis.
2. **AST Generation:** The analyzer parses the source code into an Abstract Syntax Tree.
3. **Rule-Based Analysis:** The analysis logic examines structural code patterns for potential issues.
4. **Analysis Results:** The application presents findings to help developers identify opportunities to improve code quality and efficiency.
